# Low Cost IV Curve Tracer

This repository contains a **University of Southampton research project** under **Dr. Vun Jack**.

It provides a web-based system for displaying and accessing the **I–V (current–voltage) characteristics of solar cells from the cloud**.

## Overview

The project combines:
- A hardware device setup for capturing I–V data from solar cells
- A cloud-connected software stack for storing and visualizing measurements
- A web interface for data access and analysis
